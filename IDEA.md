Quiero crear un sitio web que funcione como plataforma para busqueda de trabajo. La idea es la siguiente, la página debería mostrar un
mapa del mundo que tenga puntos que sean trabajos y que al tocar a ellos se pueda acceder a información de este. 
La idea es que esté targeteado para STEM, esto es, Física, Química, Matemática, Ingenierias Eléctrica, Mecánica, etc. La idea es que cada
una de estas disciplinas tenga subsecciones, por ejemplo, para Física uno podría tener Computación Cuántica, Nanociencia, 
Materia Condensada, Física de Superficies, Astrofísica, etc. No solo pueden ser trabajos, si no también propuestas de doctorado, masters 
o internships y que tenga la opción de elegir cual ver. También estaría bueno que se pueda listar por requisito, porque si alguien es Físico estaría bueno que pueda buscar cosas que explicitamente pidan Físicos. 
Para esto, sos libre de acceder a la web y buscar la información que quieras, así como lanzar múltiples agentes diferentes para cumplir
distintas táreas, y también hacer git commits y push cuando lo necesités pero NUNCA AGREGANDO A CLAUDE COMO COLABORADOR. La documentación
del proyecto es importante, así que me gustaría que el README del proyecto sea actualizado cuando lo veas necesario.
Es también muy importante que se pueda seleccionar la fecha para la cual uno está disponible, y que las propuestas sean acorde a esto,
y que además las deadlines sean posteriores a la fecha seleccionada.
Dado que me gustaría que esta página se actualice cuando el usuario la quiera usar y tener la información actualizada al día de la fecha,
quizás sea buena opción construir scrapers de páginas de empleos en lugar de simplemente buscar la información a lo bruto gastando tokens
cada vez que uno quiere usar la página.
Por último, si bien esto está escrito en español, la página debe estar en inglés, y vos debés pensar y escribirme en inglés.
